Grain orientation driver#

The driver template at examples/grain_orientation/template.py shows the intended high-level workflow for a multi-order-parameter Allen-Cahn grain-growth simulation:

  1. Construct a grid and seed n_orientations order-parameter fields with small-amplitude noise (the same idea as examples/mass_diffusion/template.py’s spinodal decomposition).

  2. Advance semi-implicit crystallite.grain_orientation.GrainOrientation steps – the cross-coupling term makes whichever order parameter is locally largest at a point grow and suppress the others there, so a polycrystalline structure self-organizes directly from noise.

  3. Track the dominant orientation (by magnitude, since each order parameter’s double well has minima at both +eta0 and -eta0) and the total free energy, which decreases monotonically as grains coarsen.

  4. Plot the resulting grain map at several snapshots.

See examples/grain_orientation/verification/ for the accompanying verification plots comparing this solver against the analytic planar and circular-grain equilibria.

  1"""2D Ostwald ripening (grain growth) example using the multi-order-parameter
  2Allen-Cahn ``GrainOrientation`` solver.
  3
  4``N_ORIENTATIONS`` order-parameter fields are seeded with small random noise
  5about 0, the same idea as :mod:`examples.mass_diffusion.template`'s
  6spinodal decomposition. The cross-coupling term makes whichever order
  7parameter is locally largest at a point grow and suppress the others
  8there, so a polycrystalline structure self-organizes directly from noise --
  9curvature-driven grain-boundary migration then coarsens it: small grains
 10shrink and vanish, larger ones grow, and the total free energy decreases
 11monotonically (Allen-Cahn's defining Lyapunov property). Left to run long
 12enough, coarsening runs all the way down to a single surviving grain --
 13unlike, say, a Potts/vertex model, plain multi-order-parameter Allen-Cahn
 14grain growth has nothing that stabilizes multiple grains indefinitely.
 15
 16Getting a polycrystal to nucleate from noise at all is more parameter
 17sensitive here than for spinodal decomposition. Allen-Cahn (non-conserved)
 18dynamics have no finite-wavelength selection the way Cahn-Hilliard's
 19conserved dynamics do: the linearized growth rate ``L*(a - kappa*k^2)``
 20*decreases monotonically* with ``k``, rather than peaking at some nonzero
 21``k`` the way Cahn-Hilliard's does. That does not mean the spatially
 22uniform (``k=0``) mode necessarily wins -- it means a whole band of
 23long-wavelength modes grows at comparable rates, and which one ends up
 24dominating a given region is essentially set by the noise realization
 25there. If that band's characteristic wavelength,
 26``2*pi*sqrt(gradient_energy / barrier_coefficient)``, is too large a
 27fraction of the domain, there is only room for a handful of independent
 28"cells" and one orientation's random head start tends to sweep the whole
 29domain before local competition elsewhere can develop (confirmed
 30empirically: ``gradient_energy=1e-3`` at these other parameters collapses
 31to one grain almost immediately). ``GRADIENT_ENERGY`` below is chosen
 32small enough, relative to the domain, for many independent grains to
 33nucleate, while ``shape`` is fine enough for the resulting interfaces
 34(:func:`crystallite.mass_diffusion.double_well_equilibrium_width`-scale)
 35to still land on several grid points rather than being pinned to the
 36lattice.
 37
 38Plots use the project's shared style,
 39:func:`crystallite.visualization.configure_pgf`.
 40"""
 41
 42from __future__ import annotations
 43
 44import numpy as np
 45
 46from crystallite.grain_orientation import GrainOrientation
 47from crystallite.grid import Grid
 48
 49N_ORIENTATIONS = 20
 50BARRIER_COEFFICIENT = 1.0
 51QUARTIC_COEFFICIENT = 1.0
 52CROSS_COEFFICIENT = 1.5
 53GRADIENT_ENERGY = 1.0e-4
 54MOBILITY = 1.0
 55
 56
 57def build_solver(grid):
 58    """Construct the isotropic ``GrainOrientation`` solver used by this
 59    example."""
 60    return GrainOrientation(
 61        grid,
 62        mobility=MOBILITY,
 63        gradient_energy=GRADIENT_ENERGY,
 64        barrier_coefficient=BARRIER_COEFFICIENT,
 65        quartic_coefficient=QUARTIC_COEFFICIENT,
 66        cross_coefficient=CROSS_COEFFICIENT,
 67    )
 68
 69
 70def initial_field(grid, n_orientations=N_ORIENTATIONS, amplitude=0.1, seed=0):
 71    """Return small-amplitude noise about 0 for every orientation field."""
 72    rng = np.random.default_rng(seed)
 73    return amplitude * rng.standard_normal((n_orientations,) + grid.shape)
 74
 75
 76def grain_count(eta):
 77    """Return the number of orientations that are dominant (largest in
 78    magnitude) at at least one grid point -- a simple proxy for the number
 79    of surviving grains.
 80
 81    Each order parameter's double well has minima at both ``+eta0`` and
 82    ``-eta0``, so a saturated grain is not always positive -- comparing
 83    magnitude (not signed value) is what correctly identifies which
 84    orientation has committed at a point.
 85    """
 86    return len(np.unique(np.argmax(np.abs(np.asarray(eta)), axis=0)))
 87
 88
 89def run_example(
 90    shape=(192, 192, 1),
 91    lengths=(1.0, 1.0, 1.0),
 92    time_step=0.5,
 93    steps=3000,
 94    snapshot_every=600,
 95    save_path=None,
 96    show_plot=False,
 97):
 98    """Advance a 2D Ostwald ripening (grain growth) run.
 99
100    Parameters
101    ----------
102    shape : tuple of int, default=(192, 192, 1)
103        Real-space grid shape.
104    lengths : tuple of float, default=(1.0, 1.0, 1.0)
105        Domain length in each coordinate direction.
106    time_step : float, default=0.5
107        Semi-implicit integration time step.
108    steps : int, default=4000
109        Number of time steps to take.
110    snapshot_every : int, default=800
111        Save a snapshot every so many steps.
112    save_path : str or None, default=None
113        Optional output file for a snapshot-grid PNG image.
114    show_plot : bool, default=False
115        If True, display the snapshots with Matplotlib.
116
117    Returns
118    -------
119    eta : ndarray
120        Final orientation fields, shape ``(N_ORIENTATIONS,) + shape``.
121    snapshots : list of (int, ndarray)
122        ``(step, eta)`` pairs recorded during the run.
123    energy_history : list of (int, float)
124        ``(step, free_energy)`` pairs recorded during the run.
125    """
126    grid = Grid(shape=shape, lengths=lengths)
127    solver = build_solver(grid)
128    eta = initial_field(grid)
129
130    snapshots = [(0, np.asarray(eta).copy())]
131    energy_history = [(0, float(solver.free_energy(eta)))]
132    for step in range(steps):
133        eta = solver.step(eta, time_step)
134        if (step + 1) % snapshot_every == 0 or step == steps - 1:
135            snapshots.append((step + 1, np.asarray(eta).copy()))
136            energy_history.append((step + 1, float(solver.free_energy(eta))))
137
138    if save_path is not None or show_plot:
139        try:
140            from crystallite.visualization import configure_pgf
141
142            plt = configure_pgf()
143        except ImportError:  # pragma: no cover
144            print(
145                "Matplotlib is not installed; skipping plot output for this run."
146            )
147            return eta, snapshots, energy_history
148
149        fig, axes = plt.subplots(
150            1, len(snapshots), figsize=(3.0 * len(snapshots), 3.2),
151            constrained_layout=True,
152        )
153        for ax, (step, snap) in zip(axes, snapshots):
154            grain_map = np.argmax(np.abs(snap), axis=0)[:, :, 0]
155            ax.imshow(
156                grain_map, origin="lower", cmap="viridis",
157                vmin=0, vmax=N_ORIENTATIONS - 1, interpolation="nearest",
158            )
159            ax.set_title(rf"step {step}, {grain_count(snap)} grains")
160            ax.set_xticks([])
161            ax.set_yticks([])
162
163        if save_path is not None:
164            fig.savefig(save_path, dpi=200, bbox_inches="tight")
165            print(f"Saved plot to {save_path}")
166
167        if show_plot:
168            plt.show()
169
170        plt.close(fig)
171
172    return eta, snapshots, energy_history
173
174
175if __name__ == "__main__":
176    eta, snapshots, energy_history = run_example(
177        shape=(192, 192, 1),
178        steps=3000,
179        snapshot_every=600,
180        save_path="ostwald_ripening.png",
181        show_plot=False,
182    )
183    print(f"final grain count = {grain_count(eta)}")
184    for step, energy in energy_history:
185        print(f"step {step}: free_energy = {energy:.6f}")
