crystallite.verification namespace#

The verification namespace contains small, reproducible verification cases for each physical model. These cases define initial conditions and observables (and, where a closed-form solution exists, the analytic comparison); numerical time integration or equilibrium solving belongs to the corresponding solver.

Grain orientation cases#

Verification cases for grain-orientation (Allen-Cahn) dynamics.

class CircularGrainCase(grid: Grid, barrier_coefficient: float = 1.0, quartic_coefficient: float = 1.0, gradient_energy: float = 1.0, mobility: float = 1.0, n_orientations: int = 2, active_orientation: int = 0, center: tuple = (0.0, 0.0))[source]#

Bases: object

A shrinking circular grain under curvature-driven Allen-Cahn dynamics.

A single order parameter is \(+\eta_0\) inside a disk of radius \(R\) and \(-\eta_0\) outside (the rest held at zero, the radial analog of PlanarGrainBoundaryCase’s kink profile).

The equilibrium radial profile is taken to be the flat-interface tanh profile evaluated at r - R – exact on an infinite plane, and a good approximation here whenever the interface width is small relative to \(R\). Substituting this ansatz into the Allen-Cahn equation and expanding the radial Laplacian’s curvature term, \(\nabla^2\eta = \eta'' + \eta'/r\), to leading order in \(1/R\) gives an exact cancellation of every term except the curvature term, because the flat-interface profile already solves \(\kappa\Phi'' = f'(\Phi)\) identically (crystallite.mass_diffusion.double_well_equilibrium_width()). What remains is

\[R \frac{dR}{dt} = -L \kappa, \qquad R(t)^2 = R_0^2 - 2 L \kappa t,\]

where \(L\) is mobility and \(\kappa\) is gradient_energy – notably the gradient-energy coefficient itself, not the interfacial (line-tension) energy surface_energy. The two are easy to conflate (the standard curvature-flow heuristic “velocity = mobility x surface energy x curvature” from sharp-interface theory) but are only proportional to each other up to a factor of \(\eta_0^2/\text{width}^2\) here, which is not of order 1 in general – using surface_energy in place of gradient_energy in the rate law overstates or understates the true shrink rate by that factor. surface_energy remains the correct quantity for the static excess energy of the boundary, \(F = 2\pi R\,\sigma\) in 2D (verified directly against GrainOrientation.free_energy()).

property surface_energy[source]#

Interfacial (line-tension) energy per unit boundary length.

Equal to \(\int \kappa (\Phi')^2\,dx = \tfrac{4}{3}\kappa \eta_0^2/\text{width}\), using equipartition (\(\kappa(\Phi')^2/2 = f(\Phi) - f(\eta_0)\) on the exact static profile) and \(\int \mathrm{sech}^4 = 4/3\). Sets the static excess energy \(F=2\pi R\sigma\), not the shrink rate (see class docstring).

class PlanarGrainBoundaryCase(grid: Grid, barrier_coefficient: float = 1.0, quartic_coefficient: float = 1.0, gradient_energy: float = 1.0, n_orientations: int = 2, active_orientation: int = 0, center: float = 0.0)[source]#

Bases: object

A stationary planar boundary between two grain-orientation states.

One order parameter runs from \(-\eta_0\) to \(+\eta_0\) and back across a periodic domain (a kink-antikink pair, exactly crystallite.mass_diffusion.cahn_hilliard_periodic_profile()), the rest held at zero. The single-order-parameter homogeneous term \(-\tfrac{a}{2}\eta^2+\tfrac{b}{4}\eta^4\) is algebraically crystallite.mass_diffusion.double_well_derivative() with a_param = b/4, c_alpha = -eta0, c_beta = eta0, \(\eta_0=\sqrt{a/b}\) – so the exact equilibrium profile and its width reuse that existing machinery directly, with no new interface math needed.

Elastic deformation cases#

Verification case for heterogeneous elasticity: the Kirsch problem.

class HoleInPlateCase(grid: Grid, matrix_lame_lambda: float, matrix_lame_mu: float, hole_radius: float, contrast: float = 0.001, center: tuple = (0.5, 0.5), smoothing_width: float = 0.0)[source]#

Bases: object

A circular hole (soft inclusion) in a periodic 2D isotropic plate, with the analytic Kirsch stress field for validation.

The hole is represented as a region of much softer material (contrast times the matrix’s Lame parameters, not literally zero – a true void makes the elasticity operator singular there) centered in the grid’s first two coordinates – the same “diffuse/soft approximation of a sharp feature, quantified rather than assumed” idea as crystallite.verification.CircularGrainCase. Valid against Kirsch’s infinite-plate solution only for hole_radius small relative to the domain, since the FFT solver actually sees a periodic array of holes.

periodic_analytic_solution(load, magnitude)[source]#

Exact analytic solution for the periodic array problem this grid actually represents – not the isolated-hole approximation analytic_stress() gives.

Replaces the true finite-contrast inhomogeneity with an Eshelby equivalent eigenstrain (_equivalent_eigenstrain()) over a matrix-material disk, then solves the resulting periodic (Khachaturyan-Shatalov) eigenstrain problem exactly in Fourier space, reusing ElasticDeformation.reference_green() directly (a homogeneous-medium body-force solve is exactly what a fixed eigenstrain distribution needs) with a purely analytic source term built from _disk_fourier_transform() – no discretized real-space eigenstrain array, no CG iteration.
