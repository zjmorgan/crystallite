Mass diffusion driver#

The driver template at examples/mass_diffusion/template.py shows the intended high-level workflow for a nonlinear mass-diffusion simulation:

  1. Define parent and product phases with symmetry-resolved tensor properties (crystallite.material.properties.Solid).

  2. Construct a grid and a small-amplitude initial composition field.

  3. Mix phase properties into composition-dependent mobility and gradient-energy callables (crystallite.mobility.BinaryMobility, crystallite.mass_diffusion.GradientEnergy).

  4. Advance semi-implicit crystallite.mass_diffusion.MassDiffusion steps, clipping the field back to its physical composition range each step.

  5. Plot the final microstructure.

See examples/mass_diffusion/verification/ for the accompanying verification plots comparing this solver against analytic mass-diffusion solutions.

  1"""2D spinodal decomposition example with composition-dependent mobility,
  2gradient energy, and semi-implicit time stepping.
  3
  4This example uses the nonlinear ``MassDiffusion`` solver in a minimal
  5spinodal decomposition setup. The composition field is initialized with a
  6small random perturbation about the unstable midpoint and then evolves
  7under a composition-dependent (rather than constant) mobility and
  8gradient-energy coefficient. Each is a small, reusable model object with a
  9named method -- passed directly to ``MassDiffusion`` with no wrapper
 10``lambda`` needed:
 11
 12- ``mobility`` is :class:`crystallite.mobility.BinaryMobility`, a binary
 13  A-B interdiffusion model: each species' own diffusivity is first
 14  interpolated between its value in the two pure end members, then
 15  Darken-combined and converted to a mobility.
 16- ``gradient_energy`` is :class:`crystallite.mass_diffusion.GradientEnergy`,
 17  which mixes a "parent" and "product" phase's (possibly anisotropic)
 18  gradient-energy tensor by composition -- gradient energy is properly a
 19  tensor, just like diffusivity, not a bare scalar.
 20- ``free_energy_derivative`` is :class:`crystallite.mass_diffusion.ChemicalFreeEnergy`,
 21  the fourth-order Taylor approximation to the bulk free energy,
 22  parametrized by the free-energy barrier height at the reference
 23  composition rather than the raw quartic coefficient. Composition is on
 24  ``[0, 1]`` throughout (``c_alpha=0, c_beta=1``), matching the mole
 25  fraction convention ``BinaryMobility`` expects -- mixing that convention
 26  with a ``[-1, 1]`` free energy would let the field push ``BinaryMobility``
 27  into an unphysical negative-mobility regime once it starts separating.
 28
 29The end-member diffusivity and gradient-energy tensors themselves come
 30from :class:`crystallite.material.properties.Solid`, so only the
 31independent tensor components allowed by the parent/product phases' point
 32group need to be set -- the rest are filled in (or forced to vanish) by
 33symmetry, rather than typed out by hand.
 34
 35``MassDiffusion`` uses ``scheme="semi_implicit"``: real spinodal growth
 36here is orders of magnitude slower than the time step a plain explicit
 37scheme can take before its shortest-wavelength (Nyquist) mode goes
 38unstable, so explicit stepping can only ever show either no visible
 39decomposition (small, stable time step) or a grid-scale checkerboard
 40artifact (a time step pushed large enough to see growth in a practical
 41step count) -- never real microstructure. The semi-implicit scheme treats
 42a homogeneous reference linearization of the dynamics implicitly, which
 43handles that stiffness unconditionally and lets the true nonlinear
 44dynamics evolve explicitly on top of it.
 45
 46``dealias=True`` additionally applies ``grid.lanczos_filter`` (ported from
 47the reference Fortran solver's ``sf_lanczos_filter``/``sf_filter``) to the
 48chemical potential each step, smoothly tapering its Fourier transform to
 49exactly 0 at the Nyquist frequency -- suppressing the spurious
 50high-wavenumber content the nonlinear free energy and composition-dependent
 51mobility/gradient energy generate via aliasing when evaluated
 52pseudo-spectrally.
 53
 54Plots use the project's shared style,
 55:func:`crystallite.visualization.configure_pgf`.
 56"""
 57
 58from __future__ import annotations
 59
 60import numpy as np
 61
 62from crystallite.mass_diffusion import (
 63    ChemicalFreeEnergy,
 64    GradientEnergy,
 65    MassDiffusion,
 66    double_well_curvature,
 67)
 68from crystallite.material.properties import Solid
 69from crystallite.mobility import BinaryMobility
 70from crystallite.grid import Grid
 71
 72REFERENCE_COMPOSITION = 0.5
 73BARRIER_HEIGHT = 0.25
 74
 75
 76def define_phases(point_group="432"):
 77    """Return symmetry-resolved parent/product diffusivity and
 78    gradient-energy tensors.
 79
 80    Parameters
 81    ----------
 82    point_group : str, default="432"
 83        Crystallographic point group shared by both phases (here cubic,
 84        so a single ``d11``/``kappa11`` constant is enough -- symmetry
 85        forces ``d22 = d33 = d11`` and every off-diagonal entry to zero).
 86
 87    Returns
 88    -------
 89    parent, product : Solid
 90    """
 91    parent = Solid(point_group=point_group)
 92    parent.set("diffusivity", d11=1.0e-5)
 93    parent.set("concentration_gradient_energy", kappa11=3.0e-3)
 94
 95    product = Solid(point_group=point_group)
 96    product.set("diffusivity", d11=2.0e-5)
 97    product.set("concentration_gradient_energy", kappa11=6.0e-3)
 98
 99    return parent, product
100
101
102def build_solver(grid):
103    """Construct the composition-dependent, semi-implicit MassDiffusion
104    solver used by this example.
105
106    Returns
107    -------
108    MassDiffusion
109    """
110    parent, product = define_phases()
111
112    # Binary A-B interdiffusion mobility: each species' diffusivity is
113    # interpolated between its two pure end-member values, then
114    # Darken-combined into a mobility. The end members are the
115    # parent/product phases' own symmetry-resolved (3, 3) diffusivity
116    # tensors; both species are taken to share each end member's value
117    # here, for lack of a separate per-species tracer diffusivity.
118    mobility_model = BinaryMobility(
119        d_a_in_a=parent.get("diffusivity"),
120        d_a_in_b=product.get("diffusivity"),
121        d_b_in_a=parent.get("diffusivity"),
122        d_b_in_b=product.get("diffusivity"),
123        temperature=1.0,
124    )
125
126    # Gradient-energy tensor mixed between the parent and product phases'
127    # own symmetry-resolved values, weighted by composition.
128    gradient_energy_model = GradientEnergy(
129        parent=parent.get("concentration_gradient_energy"),
130        product=product.get("concentration_gradient_energy"),
131    )
132
133    # Standard double-well bulk free energy, f(c) = 1/4 c^2 (1 - c)^2 so
134    # f'(c) = 2 c (c - 1) (2c - 1), in the barrier-height parametrization
135    # (a = 16 * barrier_height / (c_beta - c_alpha)**4 = 4.0 here).
136    free_energy_model = ChemicalFreeEnergy(
137        barrier_height=BARRIER_HEIGHT, c_alpha=0.0, c_beta=1.0
138    )
139
140    # The semi-implicit scheme needs a homogeneous reference point:
141    # mobility/gradient-energy/curvature evaluated at the mean
142    # composition, exactly matching the linear operator
143    # LinearSpectralDiffusion.decay_rate would use to describe small
144    # perturbations about that state.
145    reference_mobility = mobility_model.mobility(REFERENCE_COMPOSITION)
146    reference_gradient_energy = gradient_energy_model.gradient_energy(
147        REFERENCE_COMPOSITION
148    )
149    reference_curvature = double_well_curvature(
150        REFERENCE_COMPOSITION,
151        a=16.0 * BARRIER_HEIGHT,
152        c_alpha=0.0,
153        c_beta=1.0,
154    )
155
156    return MassDiffusion(
157        grid=grid,
158        mobility=mobility_model.mobility,
159        gradient_energy=gradient_energy_model.gradient_energy,
160        free_energy_derivative=free_energy_model.derivative,
161        scheme="semi_implicit",
162        reference_mobility=reference_mobility,
163        reference_gradient_energy=reference_gradient_energy,
164        reference_curvature=reference_curvature,
165        dealias=True,
166    )
167
168
169def initial_field(grid, amplitude=0.015):
170    """Return a small-amplitude noisy field around the unstable state."""
171    rng = np.random.default_rng(42)
172    noise = amplitude * rng.standard_normal(grid.shape)
173    return REFERENCE_COMPOSITION + noise
174
175
176def run_example(
177    shape=(64, 64, 1),
178    lengths=(1.0, 1.0, 1.0),
179    time_step=0.05,
180    steps=100000,
181    snapshot_every=2500,
182    save_path=None,
183    show_plot=False,
184):
185    """Advance a 2D spinodal decomposition run.
186
187    Parameters
188    ----------
189    shape : tuple of int, default=(64, 64, 1)
190        Real-space grid shape.
191    lengths : tuple of float, default=(1.0, 1.0, 1.0)
192        Domain length in each coordinate direction.
193    time_step : float, default=0.05
194        Semi-implicit integration time step.
195    steps : int, default=100000
196        Number of time steps to take.
197    snapshot_every : int, default=2500
198        Save a snapshot every so many steps.
199    save_path : str or None, default=None
200        Optional output file for a final PNG image.
201    show_plot : bool, default=False
202        If True, display the final field with Matplotlib.
203
204    Returns
205    -------
206    field : ndarray
207        Final composition field.
208    snapshots : list of ndarray
209        Stored composition snapshots for later plotting.
210    """
211    grid = Grid(shape=shape, lengths=lengths)
212    field = initial_field(grid)
213    solver = build_solver(grid)
214
215    snapshots = []
216    for step in range(steps):
217        field = solver.step(field, time_step)
218        # BinaryMobility's X_A * X_B degeneracy factor -- and hence the
219        # flux -- vanishes exactly at c=0/1, so once a point drifts past
220        # those bounds it stops responding to its own restoring chemical
221        # potential while neighboring, still-mobile points keep pushing
222        # mass into it: a slow secular drift with no self-correction,
223        # not visible until it eventually dwarfs the composition scale.
224        # Clipping back to the physical [0, 1] mole-fraction range after
225        # each step is the standard practical fix for this in
226        # degenerate-mobility Cahn-Hilliard schemes.
227        field = np.clip(field, 0.0, 1.0)
228        if (step + 1) % snapshot_every == 0 or step == steps - 1:
229            snapshots.append(field.copy())
230
231    if save_path is not None or show_plot:
232        try:
233            from crystallite.visualization import configure_pgf
234
235            plt = configure_pgf()
236        except ImportError:  # pragma: no cover
237            print(
238                "Matplotlib is not installed; skipping plot output for this run."
239            )
240            return field, snapshots
241
242        fig, ax = plt.subplots(figsize=(4.5, 4.5), constrained_layout=True)
243        image = ax.imshow(
244            field[:, :, 0],
245            origin="lower",
246            cmap="viridis",
247            interpolation="nearest",
248            vmin=0.0,
249            vmax=1.0,
250        )
251        ax.set_title("Spinodal decomposition")
252        ax.set_xlabel(r"$x$")
253        ax.set_ylabel(r"$y$")
254        fig.colorbar(image, ax=ax, label=r"composition $c$")
255
256        if save_path is not None:
257            fig.savefig(save_path, dpi=200, bbox_inches="tight")
258            print(f"Saved plot to {save_path}")
259
260        if show_plot:
261            plt.show()
262
263        plt.close(fig)
264
265    return field, snapshots
266
267
268if __name__ == "__main__":
269    field, snapshots = run_example(
270        shape=(64, 64, 1),
271        time_step=0.05,
272        steps=100000,
273        snapshot_every=2500,
274        save_path="spinodal_decomposition.png",
275        show_plot=False,
276    )
277    print(f"final mean composition = {np.mean(field):.6f}")
278    print(f"final std composition = {np.std(field):.6f}")
279    print(f"stored {len(snapshots)} snapshots")
