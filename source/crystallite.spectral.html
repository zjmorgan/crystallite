class GreenOperator(grid, medium)[source]#

Bases: object

Long-range Green’s operator for a homogeneous reference medium.

Solves \(A(\mathbf{k}) \cdot \hat{u}(\mathbf{k}) = \hat{f}(\mathbf{k})\), where \(A(\mathbf{k})\) contracts the medium tensor with the wavevector twice:

  • Conduction: medium (3, 3) \(\kappa_{ij}\); \(A(\mathbf{k}) = \kappa_{ij} k_i k_j\) (scalar); source/output scalar.

  • Elasticity: medium (3, 3, 3, 3) \(C_{ijkl}\); \(A_{ik}(\mathbf{k}) = C_{ijkl} k_j k_l\) (3, 3); source/output vectors, tensor axis leading.

Typical source is an eigenstrain (see apply_eigenstrain), not a raw force. k=0 mode is always zero.

Parameters:

Shape (3, 3) for conduction, or (3, 3, 3, 3) for elasticity.
