Elastic deformation driver#

The driver template at examples/elastic_deformation/template.py shows the intended high-level workflow for a static heterogeneous-elasticity solve:

  1. Build a soft circular inclusion approximating a hole (crystallite.verification.HoleInPlateCase), which constructs the spatially varying Lame parameter fields and the crystallite.elastic_deformation.ElasticDeformation solver for them.

  2. Convert a target remote stress into the macroscopic strain the solver takes as input, via solver.reference_green.apply_compliance (exact here since the reference medium is the actual matrix material).

  3. Solve for the equilibrium displacement fluctuation with a matrix-free, preconditioned conjugate-gradient iteration – no eigenstrain, no phase-field coupling, just Hooke’s law for a heterogeneous stiffness.

  4. Plot the resulting stress field.

See examples/elastic_deformation/verification/ for the accompanying comparison against the closed-form Kirsch solution for a hole in an infinite plate, under remote tension, compression, and pure shear.

  1"""2D stress concentration around a soft circular hole under remote
  2uniaxial tension, using the heterogeneous-elasticity
  3:class:`crystallite.elastic_deformation.ElasticDeformation` solver.
  4
  5A circular region much softer than the surrounding matrix (a
  6:class:`crystallite.verification.HoleInPlateCase`, with a diffuse rather
  7than sharp boundary -- the same "diffuse, not sharp" treatment used
  8everywhere else in this project) approximates a traction-free hole. Under
  9remote tension, the matrix around the hole shows the classic stress
 10concentration this solver is meant to capture: no eigenstrain, no
 11phase-field coupling, just Hooke's law for a spatially varying stiffness --
 12see :mod:`examples.elastic_deformation.verification.hole_in_plate` for a
 13quantitative comparison against the closed-form Kirsch solution.
 14
 15Plots use the project's shared style,
 16:func:`crystallite.visualization.configure_pgf`.
 17"""
 18
 19from __future__ import annotations
 20
 21import numpy as np
 22
 23from crystallite.grid import Grid
 24from crystallite.verification import HoleInPlateCase
 25
 26MATRIX_LAME_LAMBDA = 1.0
 27MATRIX_LAME_MU = 0.7
 28HOLE_RADIUS = 0.1
 29CONTRAST = 1.0e-3
 30MAGNITUDE = 0.01
 31
 32
 33def build_case(grid):
 34    """Construct the soft-hole case used by this example."""
 35    smoothing_width = 2.0 * grid.spacing[0]
 36    return HoleInPlateCase(
 37        grid, matrix_lame_lambda=MATRIX_LAME_LAMBDA, matrix_lame_mu=MATRIX_LAME_MU,
 38        hole_radius=HOLE_RADIUS, contrast=CONTRAST, center=(0.5, 0.5),
 39        smoothing_width=smoothing_width,
 40    )
 41
 42
 43def run_example(shape=(256, 256, 1), save_path=None, show_plot=False):
 44    """Solve for the stress field around a hole under remote tension.
 45
 46    Parameters
 47    ----------
 48    shape : tuple of int, default=(256, 256, 1)
 49        Real-space grid shape.
 50    save_path : str or None, default=None
 51        Optional output file for a field-map PNG image.
 52    show_plot : bool, default=False
 53        If True, display the plot with Matplotlib.
 54
 55    Returns
 56    -------
 57    solution : ElasticSolution
 58    case : HoleInPlateCase
 59    """
 60    grid = Grid(shape=shape, lengths=(1.0, 1.0, 1.0))
 61    case = build_case(grid)
 62    solver = case.solver()
 63    eps_bar = case.macro_strain("tension", MAGNITUDE, solver=solver)
 64    solution = solver.solve(eps_bar, tol=1.0e-6, max_iterations=3000)
 65    print(
 66        f"converged={solution.converged}, iterations={solution.iterations}, "
 67        f"residual={solution.residual_norm:.3g}"
 68    )
 69
 70    if save_path is not None or show_plot:
 71        try:
 72            from crystallite.visualization import configure_pgf
 73
 74            plt = configure_pgf()
 75        except ImportError:  # pragma: no cover
 76            print("Matplotlib is not installed; skipping plot output for this run.")
 77            return solution, case
 78
 79        sigma = np.asarray(solution.stress)
 80        sigma_xx, sigma_yy, sigma_xy = sigma[0, 0], sigma[1, 1], sigma[0, 1]
 81        von_mises = np.sqrt(
 82            sigma_xx**2 - sigma_xx * sigma_yy + sigma_yy**2 + 3.0 * sigma_xy**2
 83        )
 84
 85        x = np.asarray(grid.x[0])[:, 0, 0]
 86        y = np.asarray(grid.x[1])[0, :, 0]
 87
 88        fig, ax = plt.subplots(figsize=(4.5, 4.0), constrained_layout=True)
 89        im = ax.imshow(
 90            (von_mises[:, :, 0] / MAGNITUDE).T, origin="lower",
 91            extent=(x[0], x[-1], y[0], y[-1]), cmap="viridis",
 92        )
 93        circle = plt.Circle(case.center, HOLE_RADIUS, fill=False, color="w", linewidth=1)
 94        ax.add_patch(circle)
 95        ax.set_xlim(0.25, 0.75)
 96        ax.set_ylim(0.25, 0.75)
 97        ax.set_xlabel(r"$x_1$")
 98        ax.set_ylabel(r"$x_2$")
 99        fig.colorbar(im, ax=ax, label=r"von Mises $\sigma / \sigma_\infty$")
100
101        if save_path is not None:
102            fig.savefig(save_path, dpi=200, bbox_inches="tight")
103            print(f"Saved plot to {save_path}")
104        if show_plot:
105            plt.show()
106        plt.close(fig)
107
108    return solution, case
109
110
111if __name__ == "__main__":
112    run_example(save_path="hole_tension_von_mises.png", show_plot=False)
