crystallite documentation
==========================

*crystallite* is a materials simulation package built around spectral
(Fourier-space) methods on periodic grids. It provides:

- Real/Fourier-space grid setup with matching wavenumbers
- Spectral differential operators (gradient, divergence, curl, Laplacian)
- Long-range operators: Coulomb (Poisson) and homogeneous-medium Green's
  functions for conduction and elasticity

Core libraries and technologies:

- Python 3
- NumPy, SciPy for scientific computation
- CuPy for optional GPU acceleration
- Sphinx for documentation
